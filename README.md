**🌍 TripAdvisor Clone**
A simple, responsive clone of the official TripAdvisor website built using HTML and CSS. This project focuses on layout design, UI structure, and styling—no backend or advanced frontend frameworks were used.

**🚀 Features**
Fully responsive homepage layout
Navigation bar similar to TripAdvisor
Popular destinations/cards
Footer styled like the original site
Clean, structured HTML & modern CSS

**🛠️ Technologies Used**
HTML5
CSS3
